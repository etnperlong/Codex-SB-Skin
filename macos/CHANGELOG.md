# Changelog

## 1.3.0 — 2026-07-17

### 新增

- 内置主题更新为“小而美”：以微信 macOS 桌面端的克制密度、灰白层级和绿色状态语义为设计参考
- 新增 Home / Task 的浅色与深色语义契约，并为代码块提供独立背景、文字和边框 token
- 新增 Home 首屏高度、建议卡方向、间距、图标尺寸和装饰显隐 token，避免主题专用硬编码
- 新增无文字、无伪控件的抽象对话横幅素材

### 改进

- 建议卡支持紧凑横向布局，项目选择器、输入框、消息和弹层使用低圆角、细边框与弱阴影
- 浅色模式使用 `#f5f5f5` 工作区、白色内容面、`#07c160` 关键状态和 `#95ec69` 用户消息
- 深色模式使用中性黑灰层级，减少背景图片、光晕、粒子、渐变和毛玻璃对内容的干扰
- 保留原生 Codex 侧栏、消息、建议卡、项目选择器、输入框、菜单、焦点和键盘行为
- 更新入口和完整侧栏选中态统一使用微信绿，Home 的 Hero、建议卡和 820px 输入区重新对齐
- Task 页面恢复低对比度抽象对话背景，在保留微信式内容层级的同时增加主题辨识度
- 侧栏密度与排版对齐 Pencil 设计：44px 行高、6px 圆角、13px 条目字号、11px 分组标题与 58px 品牌区，均由语义 token 驱动

### 修复

- 修复浅色模式下项目侧栏悬浮详情被侧栏文字规则覆盖，导致深色 tooltip 出现黑底黑字的问题

## 1.2.0 — 2026-07-17

### 新增

- `theme.json` 升级为语义化 schema v2，提供浅色 / 深色两套完整视觉 token
- 新增侧栏、主界面、消息、输入框、卡片、项目选择器、弹层、状态色、排版、圆角、布局、阴影、模糊和动效配置
- 运行时把 136 个语义 token 映射为 CSS 自定义属性，并在浅色 / 深色壳切换时自动更新
- 保持 schema v1 用户主题兼容，加载时安全迁移到 v2 运行模型

### 改进

- 自定义主题生成器现在输出完整 schema v2，而不再只写入三种主色
- 主题 token 使用严格 CSS 值校验，拒绝包含声明注入字符的不安全配置
- 视觉 CSS 增加最终语义层，Pencil 设计变量可直接映射到主题配置

### 修复

- 全新安装或尚未创建自定义主题时，安装、启动与 doctor 检查会明确使用内置 demo 资源
- 用户主题目录已经存在但缺少 `theme.json` 时仍安全报错，不会静默掩盖不完整主题

## 1.1.2 — 2026-07-16

### 修复

- 修正内置主题引用了未随仓库发布的背景文件，恢复使用 bundled abstract demo 素材
- 更新主题配置往返测试：安装只备份外观键，不再错误断言强制切换深色模式
- 恢复原本没有 `[desktop]` 配置段的用户设置时，不再额外写入空段
- 热切换读取运行状态时复用 Codex 内置 Node.js，不再依赖系统 `python3` 或执行 `eval`
- 显式传入的 `--theme-dir` 缺少 `theme.json` 时立即报错，不再静默回退到内置 demo 主题

## 1.1.0 — 2026-07-16

### 新增

- SwiftBar 菜单栏入口（`Install Menu Bar.command`）：应用 / 暂停 / 换图 / 切换已保存主题 / 从图片文件夹加载 / 完全恢复
- 主题库（`themes/`）与图片投放目录（`images/`）动态加载，不再把 README 图库合成图当背景素材
- 按 Codex 应用浅色 / 深色自动切换皮肤壳（`data-dream-shell`）

### 改进

- CDP 已就绪时热切换主题（重启 injector + 短时注入），换图更快
- 注入校验放宽（项目选择器等可选），避免误杀已生效皮肤
- 注入守护优先 `nohup`；暂停状态与路径大小写下停止逻辑更稳
- 安装时不再强制 `appearanceTheme=dark`，只备份桌面外观相关键，便于恢复与自动适配

### 视觉

- 以原版暗色 portal CSS 为结构底，叠加 light 壳与更薄横幅遮罩，减轻「换图看不清」
- 示例纯横幅：`docs/images/banner-arina-hashimoto-pure-no-ui.png`（无人机 UI 合成）

### 说明

- `docs/images/gallery/` 仅为效果预览，不要当 `theme` 背景导入

## 1.0.0 — 2026-07-15

- 发布 macOS 通用主题制作器，而不是固定角色皮肤。
- 加入 Finder 选图、自动 JPEG 转换、主题命名和高级配色参数。
- 主页使用独立横幅，任务页使用背景与磨砂层，完整保留原生交互。
- 改为复用并验证 Codex 官方签名 Node.js，不再附带大型运行时或依赖全局 Node。
- 增加独立安装目录、桌面启动/定制/验证/恢复入口。
- 增加官方签名、CDP 端口归属、PID 身份、刷新重注入和真实 DOM 自检。
- 增加原子配置备份、精确恢复、静态测试、安装恢复循环和发布打包脚本。
- 清理固定角色内部命名；传送门主题仅作为可替换示例素材。
- 开源树：示例横幅改为无角色抽象几何图；验收截图不入库；补充 NOTICE / README 商标与安全边界说明。
